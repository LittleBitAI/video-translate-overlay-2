## Features

- Sign in with the same Google account on Windows and Android to share the library, playlists and playback position over the same local network, with no server.
- A one-hour YouTube lecture's audio now downloads in seconds instead of about 30 minutes, and phone subtitles are ready in about 41 minutes instead of about 80.
- Choosing a playlist in the library shows its videos as thumbnails at once; every screen uses the same menu.

## Installation

Android: install `video-translate-overlay-0.1.8-arm64.apk` over the existing app.
Keep the existing app installed to retain the API key, saved subtitles, and library.
This APK retains the development signing certificate used since 0.1.6.

Windows: run `video-translate-overlay-0.1.8-windows-x64-setup.exe` for the same
Windows user. The installer is unsigned; Windows may show a publisher warning.
Keep the existing app data and use an in-place upgrade.

0.1.7 announces this version in the app. Versions through 0.1.6 do not check for
updates; download and install this version manually once.

Local-network sharing needs 0.1.8 on both devices, the PC app running, and both
devices on a network where they can reach each other. The existing device library
stays separate until you confirm `기존 보관함 가져오기`.
