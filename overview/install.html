설치법 · 0.1.8

파일 하나 받아서 설치해요

설치 파일은 GitHub Releases에 있어요. Android는 APK, Windows는 설치 프로그램 하나예요. PC 프로그램이나 서버를 따로 켤 필요는 없어요. 영상과 모델을 받고 번역할 때만 인터넷이 필요해요.

준비물 본인 Gemini API 키 하나. 번역 비용은 이 키의 주인에게 청구돼요. 설치한 뒤 쓰는 법은 사용법에 있어요.

Android

  1. APK 받기

    Android 7.0 이상, ARM64 기기가 대상이에요. 갤럭시 S21 시리즈도 여기에 들어가요.

    ARM64 APK 0.1.8 받기

  2. 기존 앱 위에 설치

    받은 파일을 열어 설치해요. Android가 묻으면 그 출처에서 설치를 허용해요. 이미 앱이 있다면 지우지 말고 그 위에 설치해요.

    앱을 지우거나 앱 저장공간을 비우면 개인키, 저장한 자막, 보관함이 모두 사라져요. 중요한 자료는 미리 백업해 두세요.

Windows

  1. 설치 프로그램 받기

    Windows x64용이에요. 사용자별로 설치돼서 관리자 권한이 없어도 돼요.

    Windows x64 설치 프로그램 0.1.8 받기

  2. 같은 Windows 사용자로 실행

    이미 쓰던 Windows 사용자 계정에서 실행해 그 자리에 덮어 설치해요. 앱 데이터는 그대로 남아요.

    게시자 경고설치 프로그램에 코드 서명이 없어서 Windows가 “알 수 없는 게시자” 경고를 띄울 수 있어요.

업데이트

0.1.7부터는 앱을 열거나 다른 화면에서 돌아올 때 승인된 새 버전을 확인해요. 새 버전이 있으면 버전과 짧은 기능 설명, 내 기기에 맞는 다운로드 버튼이 떠요. 내려받아 위와 같은 방법으로 덮어 설치하면 돼요.

이 버전 알림 닫기로 닫을 수 있고, 설정 → 업데이트 확인으로 다시 볼 수 있어요.

0.1.6 이하에는 이 확인 기능이 없어요. 위 링크로 한 번만 직접 받아 기존 앱 위에 설치하면, 그다음부터는 앱이 알려 줘요.

Android APK는 0.1.6부터 쓰던 같은 서명 인증서를 그대로 써서, 지우지 않고 덮어 설치할 수 있어요.

소스에서 직접 실행하려면

Node.js 24, Rust stable, CMake, C/C++ 컴파일러가 필요하고, 실제 음성 인식까지 돌리려면 libclang도 필요해요. Windows 데스크톱 앱, 브라우저 실행, Android APK 빌드 방법은 저장소의 README에 있어요.

# 저장소 루트에서
npm ci --prefer-offline --no-audit --no-fund
# 화면과 흐름만 볼 때(받아쓰기 · 번역 대체)
PORT=8080 APP_DATA_DIR=./data npm run live -- --stand-ins
