설치법 · 0.1.8

파일 하나 받아서 설치

설치 파일은 GitHub Releases에 있습니다. 미리 준비할 것은 본인 Gemini API 키 하나입니다. 번역비는 이 키로 청구됩니다.

Android

Android 7.0 이상, ARM64 기기. 갤럭시 S21 시리즈도 해당합니다.

APK 받기 · 27.9MB

  1. 받은 APK를 열어 설치합니다. 처음이면 Android가 이 출처의 설치를 허용할지 묻습니다.

  2. 이미 앱이 있다면 지우지 말고 그 위에 설치합니다.

앱을 지우거나 앱 저장공간을 비우면 개인키, 저장한 자막, 보관함이 모두 사라집니다.

Windows

Windows x64. 사용자별 설치라 관리자 권한이 없어도 됩니다.

설치 파일 받기 · 5.0MB

  1. 쓰던 Windows 사용자 계정에서 실행합니다. 같은 자리에 덮어 설치되고, 데이터는 그대로 남습니다.

  2. 코드 서명이 없어 Windows가 “알 수 없는 게시자” 경고를 띄울 수 있습니다.

업데이트

0.1.7부터는 앱을 열 때 새 버전을 확인합니다. 새 버전이 있으면 짧은 기능 설명과 내 기기에 맞는 다운로드 버튼이 뜹니다. 받아서 위와 같이 덮어 설치하면 됩니다.

알림은 이 버전 알림 닫기로 닫고, 설정 → 업데이트 확인으로 다시 볼 수 있습니다.

0.1.6 이하에는 이 기능이 없습니다. 위 버튼으로 한 번만 직접 받아 기존 앱 위에 설치하세요. 그다음부터는 앱이 알려 줍니다.

Android APK는 0.1.6부터 같은 서명을 써서, 지우지 않고 덮어 설치할 수 있습니다.

소스에서 직접 실행

Node.js 24, Rust stable, CMake, C/C++ 컴파일러가 필요합니다. 실제 음성 인식까지 돌리려면 libclang도 필요합니다. Windows 앱, 브라우저 실행, APK 빌드 방법은 README의 소스 실행 안내에 있습니다.

# 저장소 루트에서
npm ci --prefer-offline --no-audit --no-fund
# 화면과 흐름만 볼 때 (받아쓰기 · 번역은 대체)
PORT=8080 APP_DATA_DIR=./data npm run live -- --stand-ins
