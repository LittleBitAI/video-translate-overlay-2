누르는 곳은 영상감지 하나예요

설치가 끝났다면 개인키를 한 번 저장하고, 영상을 열어 영상감지를 누르면 돼요. 나머지는 이 페이지의 순서대로 필요할 때 보세요. 아직 설치하지 않았다면 설치법부터 보세요.

메뉴는 세 개 영상 영상 주소를 열고 자막을 봐요 · 보관함 번역한 영상과 재생목록 · 설정 개인키, 계정, 업데이트. 넓은 창에서는 위쪽 탭, 휴대폰에서는 아래쪽 막대예요.

처음 자막을 만들기까지

  1. 개인키 저장

    설정의 개인키 칸에 본인 Gemini API 키를 붙여 넣고 저장을 눌러요. 번역 비용은 이 키의 주인에게 청구돼요.

    키는 Android Keystore나 Windows 자격 증명 관리자에 암호화해 저장하고, 화면에는 끝 네 글자만 보여요. 다른 기기로 옮기지 않아요.

    이게 없으면영상감지 버튼을 눌러도 작업이 시작되지 않고, 개인키를 넣으라는 안내가 떠요.

  2. 유튜브 로그인(필요할 때만)

    유튜브 계정으로 볼 영상이 있다면 설정 → 유튜브 계정 연결에서 한 번 로그인해요. 로그인하지 않아도 영상은 열 수 있어요.

    휴대폰의 유튜브 앱이나 Chrome과는 별도 세션이에요. 앱은 Google 비밀번호를 받거나 저장하지 않아요. 유튜브 로그아웃은 쿠키와 사이트 자료를 지워요.

  3. 영상 열고 영상감지

    영상에서 영상 주소를 열고, 영상 위의 영상감지를 눌러요. 그다음엔 앱을 뒤로 보내도 돼요. 진행 알림이 떠 있는 동안 계속 처리해요.

    처음 한 번은 약 60MB 음성 인식 모델을 내려받아요. 오디오와 작업 자료를 저장할 공간도 필요해요.

    걸리는 시간갤럭시 S21+에서 한 시간짜리 강연이 영상감지부터 자막 준비까지 41.2분 걸렸어요(한 번 측정). 기기와 강연에 따라 달라요.

  4. 알림을 눌러 보기

    자막 준비 알림을 누르고 영상을 재생해요. 자막은 전체 처리가 끝난 뒤에 떠요. 일시 정지와 탐색 위치도 따라가고, 광고로 판단한 구간에서는 숨어요.

    앱의 전체화면 버튼은 영상과 자막을 함께 가로 전체화면으로 바꿔요. 화면복귀나 뒤로가기로 나와요.

보관함과 재생목록

보관함에서 전체 영상이나 재생목록을 고르면 영상이 썸네일 카드로 보여요. 카드를 누르면 영상이 열려요. 저장 자막 있음이면 받아쓰기도 번역도 다시 하지 않고, 비용 없이 기존 자막이 떠요.

추가로 저장된 영상이나 HTTP(S) 영상 링크를 재생목록에 넣고, + 새 재생목록으로 재생목록을 만들어요. 링크를 넣거나 열기만 해서는 번역이 시작되지 않아요.

편집을 누르면 순서를 끌어서(또는 위로 / 아래로) 바꾸고, 재생목록 이름을 바꾸거나 지우고, 영상을 재생목록에서 빼거나 지울 수 있어요. 완료를 누르면 숨겨져요.

영상 삭제는 영상 이름을 보여 주고 한 번 더 물어요. 확인하면 그 영상의 받아쓰기, 자막, 용어표, 작업 기록, 파일이 모든 재생목록에서 지워져요. 다른 영상과 모델, 개인키는 남아요.

PC와 휴대폰 잇기

두 기기 모두 0.1.8 이상이어야 해요. 두 기기의 설정 → Google 계정으로 로그인에서 같은 Google 계정으로 로그인하고, PC 앱을 켜 둔 채 같은 네트워크에 두면 보관함, 재생목록, 재생 위치가 저절로 맞춰져요. PC는 유선, 휴대폰은 Wi-Fi여도 서로 닿으면 돼요.

로그인하기 전 기기에 있던 보관함은 따로 남아요. 옮기고 싶으면 기존 보관함 가져오기를 눌러 확인해요. 완성된 번역, 링크, 재생목록이 복사되고 원본은 그대로예요.

이 Google 로그인은 기기 사이 연결에만 써요. 유튜브 로그인과 별개이고, Gemini 개인키와 쿠키는 옮기지 않아요. 기기 로그인은 최대 30일 유지돼요.

Android 알림연결을 유지하는 동안 Android에는 연결 알림이 계속 떠 있어요. 앱을 강제 종료하면 다시 열 때까지 아무것도 받지 않아요.

이럴 땐이렇게
0.1.5 이하에서 만든 자막의 내용이 앞뒤로 밀려요그 영상에서 다시 번역을 눌러요. 받아쓰기와 시각은 그대로 두고 번역만 새로 해요. 추가 비용이 들고, 이전 번역 비용까지 합쳐 영상별 한도를 확인해요.
번역이 중간에 멈췄어요앱은 영상 한 시간에 약 1,000원 기준을 넘으면 추가 번역 요청을 멈춰요. 코드에 넣은 단가와 환율로 계산한 값이에요.
Google이 앱 안 로그인을 막아요유튜브 로그인은 건너뛰어도 영상을 열 수 있어요.
다른 기기에 보관함이 안 보여요두 기기가 0.1.8 이상인지, 같은 Google 계정인지, PC 앱이 켜져 있고 같은 네트워크에 있는지 확인해요. 휴대폰이 모바일 데이터에 있으면 PC에 닿지 않아요.
새 버전 알림을 닫았는데 다시 보고 싶어요설정 → 업데이트 확인을 눌러요. 닫았던 버전도 다시 보여요.
앱을 강제 종료했어요앱을 다시 열면 저장한 진행 지점부터 이어서 해요.
