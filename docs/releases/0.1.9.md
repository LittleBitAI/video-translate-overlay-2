## Features

- On Windows, speech is now written on the graphics card (NVIDIA, AMD or Intel): a 23-minute lecture is transcribed in about 1 minute on an RTX 3080, where 0.1.8 took over 2 hours to finish it. A PC without one stays on the CPU with lighter decoding.
- After a video's speech is written, the app frees the speech model's memory (about 1.7 GB, and the graphics card's memory) instead of holding it until it closes.
- In fullscreen the subtitles grow with the video; a maximized Windows window uses its full width for the video, library and settings.

## Installation

Android: install `video-translate-overlay-0.1.9-arm64.apk` over the existing app.
Keep the existing app installed to retain the API key, saved subtitles, and library.
This APK retains the development signing certificate used since 0.1.6.

Windows: run `video-translate-overlay-0.1.9-windows-x64-setup.exe` for the same
Windows user. The installer is unsigned; Windows may show a publisher warning.
Keep the existing app data and use an in-place upgrade.

0.1.7 and 0.1.8 announce this version in the app. Versions through 0.1.6 do not
check for updates; download and install this version manually once.
