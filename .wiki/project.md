# video-translate-overlay-2 — a Tauri app that turns foreign-language tech lectures into Korean subtitles on the device

What it is for. A user opens a lecture video (YouTube or another site) inside
the app and presses the 영상감지 (video detect) button on the overlay drawn
over it. The app downloads the audio, transcribes it on the device with
whisper.cpp, translates the text with `gemini-3.1-flash-lite`, stores Korean
subtitles timed to the speech with no drift (밀림 현상), and sends a
notification when they are ready. The job keeps running with the app in the
background. The target cost is about 1,000 KRW per hour of video, which is
why the app transcribes locally and translates only text. Voice conversion
into a voice the user picks is a later extension and is not built
(assumption A2). The user's guide is `README.md`. The design is in
`docs/design/`: `backend.md` has the stack, assumptions A1–A7, the data model
and scenarios F1–F6; `api.yaml` has the command contract; `frontend.md` has
the two screens, S1 `/` and S2 `/preferences`.

How the parts talk. The screens and the overlay call Tauri commands P1–P9
(`src-tauri/src/commands.rs`). The overlay on a site's page is allowed only
P6–P8 (`src-tauri/capabilities/`). The app itself opens no port. `vto-web`
(`src-tauri/src/web.rs`) is a separate program that serves the same screens
and commands over HTTP on `127.0.0.1:$PORT`, for use in a browser.
`src-tauri/src/pipeline.rs` runs one job at a time: download, write
(transcribe), translate, notify. It records each step in SQLite in the data
folder, so a killed process resumes where it stopped. On Android the job runs
under a foreground service that starts when 영상감지 is pressed
(`src-tauri/src/android.rs`).

Build, run and test.

- Prerequisites: Node.js 24, stable Rust, CMake (libopus is built from
  source) and a C/C++ compiler; then `npm ci` at the root.
- Gate: `gate_cmd` in `.wiki/adapter.toml`, the same line as the README's
  테스트 section and CI. See [[repository-gate]].
- Live in a browser: set `PORT` and `APP_DATA_DIR`, then run `npm run live`
  (`scripts/live.mjs`). The adapter's `live_cmd` adds `--stand-ins`, which
  fakes Gemini, YouTube's audio and the model. Stop it with Ctrl+C;
  `live.mjs` passes the signal on to `vto-web`.
- On-device model: set `LIBCLANG_PATH` to build with the `whisper` feature.
  Without it, a job stops at the write stage.
- Desktop app on Windows: `cargo run` with `--features app` and
  `--bin video-translate-overlay` (see `src-tauri/README.md`).
- Android: `cargo tauri android build` (see "Build for Android" in
  `src-tauri/README.md`). It has run only on the emulator, not yet on the
  Galaxy S21 Ultra.
- The key can be stored only on Windows (Credential Manager) and Android
  (Keystore). macOS and Linux refuse to save it unless `--stand-ins` is set.
