## Installation

Android: install `video-translate-overlay-0.1.7-arm64.apk` over the existing app.
Keep the existing app installed to retain the API key, saved subtitles, and library.
This APK retains the development signing certificate used for 0.1.6.

Windows: run `video-translate-overlay-0.1.7-windows-x64-setup.exe` for the same
Windows user. The installer is unsigned; Windows may show a publisher warning.
Keep the existing app data and use an in-place upgrade.

Versions through 0.1.6 do not check for updates. Download and install this version
manually once; later approved versions can be announced in the app.
